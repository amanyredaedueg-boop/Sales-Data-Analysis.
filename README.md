# Sales Data Analysis

## 📌 Project Overview

This project focuses on analyzing sales data to discover useful insights about sales performance, products, categories, regions, and profit.

The project was built as part of **Day 03 – Build It: Mini Project** at Arabian Academy.

## 🎯 Project Objectives

* Analyze total sales and total profit
* Identify the best-performing categories and sub-categories
* Find the top 10 products by sales
* Analyze sales over time
* Compare sales across different regions
* Explore the relationship between discount and profit

## 🛠️ Tools & Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Google Colab

## 📊 Analysis Performed

The project includes:

* Data loading and exploration
* Data cleaning
* Total sales and profit analysis
* Sales analysis by category
* Sales analysis by sub-category
* Top 10 products by sales
* Yearly sales analysis
* Monthly sales analysis
* Regional sales analysis
* Discount and profit analysis
* Data visualization

## 📁 Project Files

* `Sales_Data_Analysis.ipynb` — Complete analysis notebook
* `Superstore.csv` — Dataset used for the analysis

## 💡 Key Insights

The analysis helps identify the strongest categories, products, regions, and sales periods, while also exploring the relationship between discounts and profitability.

## 🚀 Project Goal

The goal of this project is to transform raw sales data into meaningful insights using Python and data analysis techniques.
